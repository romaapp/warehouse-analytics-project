# Warehouse Analytics

Pet-project на PostgreSQL.

Проект моделирует работу Warehouse Management System (WMS).

## Реализовано

- Owner
- Warehouse
- Zone
- Location
- Product
- Transport Package
- Stock

## Используемые технологии

- PostgreSQL
- SQL
- DataGrip
- Git

## Что изучается

- Нормализация данных
- Проектирование БД
- SQL
- Аналитические запросы
- Оптимизация запросов
