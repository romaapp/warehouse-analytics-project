# Бизнес-правила WMS

- На одной транспортной упаковке хранится только один товар.
- Смешение партий запрещено.
- Остаток создается при приемке.
- Пустые транспортные упаковки не создаются.
- Владелец хранится на уровне транспортной упаковки.
- Базовая единица измерения используется для хранения количества.
